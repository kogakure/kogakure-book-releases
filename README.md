# 木隠 kogakure – the book

The free ebook of [kogakure.de](https://www.kogakure.de): the history, philosophy and techniques of the ninja, in German and English.

This repository only holds the releases. Every [release](https://github.com/kogakure/kogakure-book-releases/releases) has the EPUB and the PDF of each language, the cover and `SHA256SUMS` (check them with `shasum -a 256 -c SHA256SUMS`).

The book's page, with the downloads and ways to support it: [kogakure.de/en/book](https://www.kogakure.de/en/book/)
